# Module planner

A cleaner way to choose Imperial College London MSc Advanced Computing modules
(Department of Computing, 2026-27): toggle modules on and off, see your week, and
see what matters for each module in one place: the exam/coursework split, the
class average, student ratings, who teaches it and whether that changed, whether
lectures are recorded, coursework deadlines and conflicts with your other picks.

Your plan is saved in your browser, and "Copy plan link" gives a URL that restores it.

## Data

`public/data.json` is generated by `pnpm data` (`scripts/fetch.ts`) from:

- **Imperial's timetable (CELCAT):** weekly sessions, rooms, lecture capture, lecturers.
- **Scientia:** modules, ECTS, exam/coursework split, exam slots, coursework pieces.
- **The DoC exams site:** published class averages.
- **[Rate My Modules](https://www.ratemymodules.co.uk/icl/adv-comp):** scores and review
  counts only (no review text), with a link back.
- **The Wayback Machine:** past lecturers, from archived module pages (cached in
  `data/wayback.json`).
- **`data/notes.yaml`:** hand-written one-liners (coursework, exam, examiners' feedback,
  the main caveat, a review summary in our own words) and corrections.

The Imperial sources need a student login, so the script runs locally with the
author's read-only CLI tools (`imperial-doc`, `imperial-timetable`); the site itself
only reads the generated JSON. No personal data is included.

Contributions: see [CONTRIBUTING.md](CONTRIBUTING.md).

Everything is unofficial and can be out of date: check Scientia before choosing.

## Develop

```sh
pnpm install
pnpm dev      # http://localhost:5173
pnpm build    # type-check and build to dist/
pnpm data     # refresh public/data.json (needs the Imperial CLIs)
```

Vite, React, TypeScript, Tailwind and shadcn/ui (Base UI). The dataset's shape is
defined once in `src/data/schema.ts` (zod) and shared by the script and the app.
